# Real Estate Website Pricing Guidance

This project is a reusable real estate website platform, not just a one-off website build. Pricing should account for the value of the existing system, customization work, launch support, hosting, and ongoing maintenance.

## Baseline Costs

- Initial software/tooling spend: about $204
- Initial modification and launch time: about 10 hours
- Ongoing hosting/software costs: about $25/month
- Hourly rate range: $55-$75/hour

## Suggested One-Time Setup Pricing

### Basic Implementation: $2,500-$4,500

Use this for a smaller client who needs a straightforward branded deployment.

Includes:

- Branding, colors, and logo setup
- Content/page setup
- Listings setup
- Basic admin training
- Deployment
- Basic SEO/settings configuration

### Standard Real Estate Site: $5,000-$8,500

Use this for most serious real estate clients.

Includes:

- Everything in Basic Implementation
- Buyer/seller client portal setup
- Vercel Blob/media setup
- Meta/Facebook page integration
- Analytics, SEO, legal pages, and theme configuration
- Moderate design customization

### Premium Custom Build: $9,000-$15,000+

Use this for higher-end agents, brokerages, or clients requiring custom workflows.

Includes:

- Custom layouts and design systems
- Custom client workflows
- CRM/MCP automations
- Advanced integrations
- Complex imports/migrations
- Training and documentation
- More hands-on launch support

## Suggested Monthly Pricing

### Hosting / Light Maintenance: $75-$150/month

Includes:

- Hosting management
- Basic uptime checks
- Minor dependency/security checks

### Managed Care Plan: $200-$350/month

Includes:

- Hosting
- Uptime checks
- Backups/check-ins
- Minor text/image updates
- Dependency/security updates
- Basic support

### Growth / Support Plan: $500-$1,000/month

Includes:

- Monthly feature improvements
- SEO/content support
- Social posting assistance
- Analytics reporting
- More hands-on support

## Licensing / Platform Model

If clients are using this reusable codebase as a platform, separate the pricing into:

- Implementation fee: $4,000-$10,000
- Monthly platform/support/license: $150-$500/month

This avoids selling only labor and better reflects the value of the reusable system.

## Recommended Packages

### Smaller Client

- Setup: $3,500-$4,500
- Monthly: $150/month
- Extra work: $65/hour

### Standard Client

- Setup: $6,500
- Monthly: $250/month
- Extra work: $75/hour

### Higher-End Agent or Brokerage

- Setup: $8,500-$12,000
- Monthly: $350-$750/month
- Extra work: $75/hour or scoped separately

## Positioning Note

Do not anchor pricing only to the 10 hours spent modifying and launching the first version. Anchor pricing to:

- Replacement value
- Business value
- Reusable platform value
- Launch and support expertise
- Ongoing maintenance responsibility

For a serious client implementation, avoid charging less than about $4,500-$6,500 unless the scope is intentionally very small.
